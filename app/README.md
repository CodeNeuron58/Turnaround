# app

The Turnaround web app — three screens:

- **Plan** — pick or upload a route, set a start time, add an emergency contact
- **On trail** — the briefing, the safety-timer state, and the turn-back time
- **I'm out** — check in, close the trip, and record the actual time

React + Vite + TypeScript. The plan and briefing are cached here for offline use on the trail.
